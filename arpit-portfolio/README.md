# Arpit Pandey Portfolio

Static responsive portfolio inspired by the supplied reference.

## Run locally
Open `index.html` directly, or run:
- VS Code Live Server
- `python -m http.server 5500`

Then visit http://localhost:5500

## Customize
Edit `index.html` for content, links and project details.
Edit `style.css` for colors/layout.
Replace `assets/favicon.svg` and add a profile image if desired.
